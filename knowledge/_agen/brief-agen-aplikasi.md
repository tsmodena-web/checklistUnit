## Tugas
a. Audit UI (keseragaman dengan standar) dan UX (alur langkah, keterbacaan di HP 390px, ukuran sentuh ≥44px, kontras WCAG AA, fokus keyboard, status error/kosong, konsistensi pola antar aplikasi) dari screenshot dan kode. Telusuri semua layar utama (halaman awal, setiap langkah/pilihan form, preview output). Beri skor UI dan UX 0–100 dan daftar temuan {severity: tinggi|sedang|rendah, area, issue, fix}. area salah satu: warna|tipografi|spasi|komponen|alur|aksesibilitas|mobile|bahasa|output.
b. Bila boleh PR: kerjakan di worktree terpisah: `git -C <clone> worktree add /tmp/work/<id> -b ui-review/<minggu> <BASE>` (jangan kerja di clone utama). `npm install` bila perlu. Perbaiki temuan yang bisa diselesaikan hanya dengan tampilan, HANYA di src/index.template.html (jangan sentuh config/), lalu `node tools/build.mjs`. Cara paling aman: tambahkan/ubah aturan CSS (mis. blok override di akhir <style>) dan atribut kelas/markup pembungkus murni tampilan; jangan ubah JS.
c. Verifikasi wajib sebelum commit, dengan salinan "sebelum" = index.html dan src/index.template.html di BASE:
   (1) build berhasil;
   (2) semua konstanta data (const berisi data di <script>, baik di template maupun index.html hasil build) identik sebelum dan sesudah — evaluasi di node `vm` lalu `assert.deepStrictEqual`; lebih baik lagi tunjukkan bahwa seluruh isi <script> identik byte-per-byte;
   (3) teks halaman identik: Playwright, untuk tiap layar utama (halaman awal, setiap langkah/pilihan form, preview output) bandingkan document.body.innerText sebelum dan sesudah pada viewport 390 dan 1280 — WAJIB identik. Catatan: text-transform CSS mengubah innerText, jadi jangan pakai text-transform baru;
   (4) output JPG/PDF: ukuran (getBoundingClientRect / offsetWidth/Height) elemen area output/canvas tidak berubah, dan CSS untuk elemen output tidak disentuh.
   Bila salah satu gagal, batalkan perubahan yang menyebabkannya lalu ulangi verifikasi. Pastikan `git diff --stat BASE` hanya berisi src/index.template.html dan index.html (dan file build lain yang memang dihasilkan build, bukan config/).
d. Commit dengan pesan persis:
   "UI: <ringkasan> (<minggu>)" + baris kosong + "Co-Authored-By: Claude <noreply@anthropic.com>"
   `git push origin ui-review/<minggu>`, lalu buka PR ke BASE:
   `gh api repos/tsmodena-web/<repo>/pulls -f title="UI: <ringkasan> (<minggu>)" -f head=ui-review/<minggu> -f base=<BASE> -f body="..."`
   Body (Bahasa Indonesia): daftar perubahan, temuan yang ditangani, hasil keempat verifikasi, catatan "Tidak ada teks, data, atau output yang berubah (K-0001)", dan diakhiri dengan:
