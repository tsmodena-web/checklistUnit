# Persetujuan Pemasangan

Form 3 langkah (Informasi, Pemeriksaan, Konfirmasi) saat lokasi pemasangan berisiko: indikasi per area dengan level Berisiko / Waspada / STOP, edukasi konsumen, tanda tangan, output 1:1 JPG/PDF.

- Repo: `tsmodena-web/PersetujuanPemasangan` · config: form, products, areas, decisions, reference
- Id indikasi (`l1`, `a3`, …) dipakai di draft; area `lainnya` wajib ada
- Dibuka dari [[Form Service Result]]
